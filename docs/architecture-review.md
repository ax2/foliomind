# FolioMind 架构与整体实现 Review

## 同源窗口凭据同步（2026-09-05）

保存或清除凭据成功后通过 BroadcastChannel 通知同源的其他窗口。消息只含固定类型和随机窗口 ID，不传输密钥、前缀或配置。接收窗口立即清空旧数据、取消旧请求并读取已鉴权的 Host 状态；读取失败进入可重试状态。启动读取和稍后的本地保存使用代次保护，旧读取不会覆盖新会话。

范围：同源且支持 BroadcastChannel 的已打开窗口。不同端口、独立桌面进程以及未经过本应用的凭据修改仍需 Host 层版本与重同步机制，尚未完成。当前信号仅在凭据保存/清除后发送。

## 同前缀凭据替换补充审查（2026-09-05）

上一阶段的前缀比较不足以识别前 8 位相同的不同凭据。设置页现在仅在 Host 保存或清除成功后，显式通知 Store 清理旧数据并推进内存中的 credentialGeneration；自动刷新订阅该代次。失败保存保留原数据，手动策略继续等待显式刷新。

本次代次用于当前窗口，不是 Host 跨进程凭据版本；其他已打开窗口对凭据轮换的即时感知仍需补齐，不能据此宣称跨窗口隔离已完成。

## 频率与触发

- 每个正式 Release 前运行一次，与 `npm test`、`npm run build`、安全审计和桌面端构建一起记录。
- 快速迭代期间每两周人工 Review 一次；涉及数据渠道、凭据、状态 schema、Tauri Host 或安装升级逻辑时立即追加一次专项 Review。
- 当连续两个版本出现同一类失败、数据延迟或用户无法恢复时，必须升级为重构候选项，而不是继续增加补丁。

## 人工检查清单

1. 数据边界：页面是否只消费真实 CAP 返回；缺失、失败、过期和部分数据是否分别呈现；是否存在示例数据或由其它字段推算出的数值。
2. 性能与成本：是否复用固化 CAP 工具和短时缓存；并发、超时和重试是否有上限；CAP 与模型网关费用是否在开发面板可追溯。
3. 安全与隐私：API Key、模型配置、提示词和原始响应是否保持在 Host/运行时边界内；日志、备份和错误信息是否脱敏。
4. Web/桌面一致性：状态 schema、错误恢复、取消、通知和开发面板是否共用同一语义；桌面升级是否覆盖安装而不要求先卸载。
5. 可维护性：跨页面逻辑是否已提取为纯函数；重复的 provider 适配、状态归一化和数据状态文案是否需要合并；测试是否覆盖失败和空态。
6. 发布可靠性：版本号、PRD 阶段、Release tag、安装包、校验和及升级路径是否一致；失败时能否从日志定位到接口、参数、返回摘要和原因。

Review 结论应记录在对应 PR 或 Release notes 中，至少包含“继续演进 / 优先重构 / 暂停发布”之一和下一阶段验收条件。

## 最近一次专项 Review（2026-09-03 · Stage 3CK）

结论：继续演进。

- 发现 Local Host 的原子 JSON 写入依赖进程 `umask`，用户状态、集成设置和工具缓存在宽权限环境下可能被同机其它用户读取；桌面 Host 的临时文件也没有统一权限收紧。

- 该改动不跨越状态锁或慢调用，不改变 schema、备份和费用账本。下一阶段继续补充真实 Web/桌面并行写入的权限与备份恢复烟测，并在平台签名密钥可用后完成干净安装、覆盖升级和卸载恢复烟测。

## 最近一次专项 Review（2026-09-02 · Stage 3CH）

结论：继续演进。

- 发现 Web Host 与桌面 Host 的 CAS 保护只依赖各自进程内的队列/Mutex；两个进程同时保存时仍可能读取同一 revision 并竞争原子替换。
- 现在两端共用 `.user-state.json.lock` 独占锁文件，写入随机 owner token，等待超过 5 秒返回 `USER_STATE_BUSY`，超过 30 秒的崩溃遗留锁才允许回收，释放时会核对 token 防止误删新 owner 的锁。
- 锁只覆盖状态读取、revision 校验和原子写入，不跨越网络/模型调用；下一阶段继续补充真实 Web/桌面并行写入烟测，以及平台签名密钥可用后的干净安装、覆盖升级和卸载恢复烟测。

- 现在 Host 仅沿白名单容器键、有限深度和有限数组范围寻找第一条含有限正价格的记录，并统一映射价格、涨跌、昨收、成交额和时间别名；无关对象不会被任意遍历。
- 零、负、不可解析或空响应仍 fail closed，不写入缓存、不生成假行情；固定 CAP、来源、费用、取消和用户状态边界保持不变。
- 后续风险：新增 provider 外壳时必须先补充白名单与真实响应测试，不能放宽为任意深度/任意字段扫描，以免误识别历史或敏感数据。
